PLINK for Livestock Genomics

A step-by-step tutorial for beginners and intermediates in population genetics

Author

Ismaila Emmanuel Oluwasegun

Published

17 November 2026

Welcome

This is a practical guide to PLINK for people who work with livestock SNP data. You do not need to be a programmer. If you can type a command and read a table, you can follow every chapter.

I wrote this tutorial because most PLINK material is written for human genetics. The ideas are the same in cattle, sheep and goats, but the details are not: we have 29 cattle autosomes instead of 22, we have big half-sib families, we mix breeds, and our pedigrees are often wrong. Every example here uses livestock data, and every PLINK output you see was produced by actually running the command shown. The few commands for other programs that could not be installed where this book was built (BEAGLE, SHAPEIT, Minimac, GCTA, GEMMA) are clearly marked as not run.

How this book works

Each chapter follows the same teaching style:

  1. The idea, in plain words, usually with a picture.
  2. The command, ready to copy.
  3. The real output, exactly as PLINK prints it.
  4. What it means, and what you should do next.
  5. Exercises at the end of the chapter: practice questions on the same data, with hidden answers, and one harder challenge.

The data

We use two kinds of data.

A simulated cattle dataset (361 animals of three breeds, 4,800 SNPs). Because it was simulated, we know the truth: I hid lab errors (bad samples, a duplicate, a wrong sire, sex mix-ups, strand flips) and real genetic effects in it, and the chapters show how PLINK finds each one.

Two real public datasets: 500 genotyped cattle with a pedigree (from the synbreedData R package) and 100 sheep of two breeds, Jacob and Navajo-Churro, published by Kijas and colleagues (2016) and shipped with the detectRUNS R package. These show what real data look like, which is always a little messier than a simulation.

Everything is in the data/ and scripts/ folders of the GitHub repository, so you can repeat every step.

Which PLINK?

PLINK has three versions that are still in use. This book uses PLINK 1.9 for almost everything, gives the PLINK 2.0 command in a blue box, and uses PLINK 1.07 only for the old tools that newer versions dropped (haplotype tests and CNV analysis). Chapter 1 explains the differences.
